API Reference

Simple, predictable endpoints

RESTful JSON API. One header, one response. No SDK required.

GET /geo/{ip}
curl -H "Authorization: Bearer <token>"
     https://api.yourdomain.com/geo/1.1.1.1

# 200 OK
{ "ip": "1.1.1.1", "country": "Australia", "city": "Sydney", ... }
POST /geo/batch
curl -X POST -H "Authorization: Bearer <token>"
     -H "Content-Type: application/json"
     -d '{"ips": ["8.8.8.8", "1.1.1.1", "9.9.9.9"]}'
     https://api.yourdomain.com/geo/batch

# Returns array of geo objects — up to 100 IPs per request
GET /geo/me
curl -H "Authorization: Bearer <token>"
     https://api.yourdomain.com/geo/me

# Resolves the caller's own IP address automatically
